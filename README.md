#Life’s Greatest Asset: The Self

我们应该把自己当做一个作品去雕琢，保护好自己的注意力，专注于自我提升。
这是一个被说包浆了的话题，但我想表达的是长期主义和复利总是难以坚持的根源在于，我们大多数都是普通人，没有那么多选择，没有托底，我们做出的每一个选择对我们的人生都会进行不可逆的影响，所以对于不确定的未来，我们总会充满怀疑态度，这是人性，这也是对人生的一种负责，但恰恰是这样的思虑，让我们在面对看不到的未来的时候显得不是那么坚定。
所以我做这个项目的灵感就来源于如果我们把我们投资自己的过程进行一个量化，把自己当作一个资产去进行操作，我们可以清晰地发现我们虽然短期内会有波动，但我们的总体趋势一定是上扬的。

 So，
We are each our own greatest asset.
